# Game-VOD transcript reference

Read when fetching, extracting, validating, or consolidating official per-game VOD transcripts or `GOBS-*` observations.

## Why this layer exists

The 27 broadcast sources do not cover 45 series. The canonical `games.vod_url` column has **173 links / 172 unique official per-game VODs**, almost all different from the 27 broadcasts. They are Indonesian auto-captions and can close the source gap; verify current fetch and match coverage in the manifest.

Manifest: `analysis/evidence/game-transcript-manifest.json`. Cache: `analysis/cache/game-transcripts/<video_id>.json`. Do not edit cache files.

## Fetch

The fetch tool lives outside this repo at `D:\! Coding\~ shit projects\get-youtube-transcript` (verified 2026-11-15; vendored `youtube_transcript_api`).

```python
from youtube_transcript_api import YouTubeTranscriptApi
fetched = YouTubeTranscriptApi().fetch(video_id, languages=["id"])
snippets = [{"start": s.start, "duration": s.duration, "text": s.text} for s in fetched]
```

- Prefer Indonesian (`id`). Do not silently use the English auto-dub for quote provenance; if only English exists, record `language: "en"` and say so.
- After a batch, YouTube may return `IpBlocked` / HTTP 429. Use the project fallback:

```python
from get_transcript import fetch_from_invidious
snippets = fetch_from_invidious(video_id, "id", True)  # Invidious, Indonesian
```

- A cache file is `{video_id, language, snippets:[{start,duration,text}]}`. Reuse `status: ok` manifest rows; retry only errors.
- Record `source: "invidious"` when the mirror was used.

## Observe

Schema: `analysis/evidence/game-observation-schema.json`. Ledger: `analysis/evidence/game-observations/<match_id>.jsonl`.

Required shape:

- `observation_id`: `GOBS-<match>-G<game>-NNN`
- `match_detail_id`, `game_no`
- `source_id`: `src-game-<video_id>`
- `video_id`
- `snippet_start`, `snippet_end`, `start_s`, `end_s`
- exact `quote`, `quote_sha256`
- `claim`, `claim_type`, `topic`, `entities`, `confidence`, `status`

Rules:

- The quote must be an exact substring of the **joined snippet texts** (single spaces between snippets). Do not paraphrase the quote.
- The snippet range must contain the whole quote; `start_s` is the first snippet start, `end_s` is the last snippet start + duration.
- Keep claims narrower than the quote. A caster statement is `commentary` or `observation`, not a database fact.
- Normalize only clear ASR names in entities; preserve the ASR spelling in the quote. Example: `Andoriu` in the quote → `ANDORYUUU` in entities.
- One game only. Do not use a G1 quote as G2 evidence.

Validate:

```text
python tools/validate_game_observations.py --observations analysis/evidence/game-observations/1037.jsonl
```

It checks schema keys, quote presence/hash, snippet and time bounds, ID/manifest consistency, and warns on unknown players/teams/heroes. It cannot judge overreach; spot-check 2–3 claims against the surrounding transcript.

## Consolidate

- Add accepted records to the match report under `## Game transcript evidence (per-game VODs)`.
- The DB block note is generated by `tools/build_match_evidence.py`; it counts accepted game observations for non-plan matches. Run `--check` after editing.
- Do **not** route `GOBS-*` through `tools/route_transcript_observations.py`; it is built for the 27-source `TOBS-*` ledger. Cross-link manually only when the claim is specific.
- `tools/build_coverage_matrix.py` reports game-transcript availability, game-observation matches, and combined transcript evidence. The 1037 pilot validated the layer; verify current counts in the coverage matrix.

## Scale

The template is 1037. Batch 3–5 matches per subagent. Pre-filter each transcript around `turtle`, `lord`, `blood`, `draft`, `base`, `defense`, `objektif`, `menang`, `selesai` so the subagent reads bounded windows, not 1,000+ snippets. Require 5–8 observations per match, validate all quotes, then spot-check.

## Limits

- Auto-captions, no speaker labels, ASR errors.
- Caption time is not the broadcast clock; do not equate it with the visual game clock.
- The database still has no objective counts, gold timelines, vision, or communications.
- Per-game VODs are **not** zero-clock sources: first HUD is `00:21` (1036 G1) and `00:42` (1036 G2). See `references/visual-proof.md`.
